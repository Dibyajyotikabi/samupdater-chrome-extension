# SamUpdater extension privacy policy

SamUpdater checks the latest listed software release for the Galaxy device and region you choose. The catalogue is bundled with the extension. When you open the popup, it requests SamUpdater's public firmware feed for recent releases. When you click **Check update**, it sends the selected model number and CSC code over HTTPS to return the matching release. Both requests omit account credentials and cookies.

The extension itself has no analytics or advertising and does not store your selections, read your browsing history, or read unique device identifiers such as IMEI or serial numbers. SamUpdater's server logs can include standard request details such as IP address, browser type, and requested endpoint. See the [SamUpdater website privacy policy](https://samupdater.com/privacy-policy/) for how the site handles its logs. When you open a link from the popup, the destination site's privacy policy applies to that visit.

For privacy questions, [contact SamUpdater](https://samupdater.com/contact/).
